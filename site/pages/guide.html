Getting started

Build it, add a documentation source, read it offline. Ten minutes, most of which is the first crawl being polite.

There is no release yet. No DMG, no Homebrew tap. Everything below assumes you built from source, which is currently the only way to run Tome.

Build it

You need Rust, Node, and macOS on Apple Silicon.

$ git clone https://github.com/alexnodeland/tome
$ cd tome
$ npm install
$ cargo build --release -p tome-cli
$ npm run tauri dev

Put the CLI on your PATH — target/release/tome. The app and the CLI must be the same build, because that is what makes them resolve the same library.

Check that they agree before going further. tome status prints where the library lives; the app shows the same paths.

one library an integration test runs the real binary and asserts it resolves the paths the app links against 
$ tome status
Tome 0.0.0 (com.alexnodeland.tome)
  state:  ~/Library/Application Support/Tome
  cache:  ~/Library/Caches/Tome
  db:     ~/Library/Application Support/Tome/tome.db

Add a source

$ tome add https://docs.python.org/3/

Tome fetches the homepage, works out what built the site, proposes a configuration, and asks before doing anything. Confirm and it pulls.

Detection decides “act, or ask” — never “act wrongly”. Below the confidence threshold Tome falls back to the generic scraper, which is correct for every platform and merely keeps more page furniture than a tuned profile would.

≥ 0.80 confidence to act without asking · one site in the 128-page corpus is unclassifiable from a homepage, and correctly says so

The fetch goes through the same path as everything else: robots.txt, the rate limit, and the SSRF guard all apply. Detection is the first thing Tome does to a host you name, which makes it exactly the wrong place to skip any of them.

Useful flags

Flag What it does
--yes Skip the confirmation. Required when stdin is not a terminal, and with --json.
--name <id> Set the source id yourself instead of deriving it from the URL.
--category <name> Group it in the library.
--insecure Allow http and private hosts. For an intranet mirror you own — nothing else.

Or write the configuration yourself

A source is one YAML file in the sources directory. This is the whole schema for a typical site: 

schema_version: 1
name: Polars
source:
  type: generic
  url: https://docs.pola.rs/
  generic:
    max_depth: 4
    max_pages: 5000
category: Python
sync:
  strategy: scheduled
  schedule: weekly

strategy takes manual, on_launch, scheduled or watch. weekly is a schedule, not a strategy — the parser rejects that mistake by name, because it is the one people make most.

Read and search

Open the app. The library is on the left, the page outline on the right.

Key Does
⌘K Search everything, with snippets and source scoping
⌘F Find within the open page
⌘[ / ⌘] Back and forward

Or from the terminal:

$ tome search "async iterator" --scope python
$ tome search "@with_capacity"          # pages that DECLARE it
$ tome search "os.cpus()" --json | jq

If a term appears nowhere in your library, Tome corrects it and says so — a search that quietly answers a different question than the one you asked is worse than one that reports what it did.

did you mean corrections come from prose fields only, never code: identifier vocabularies have dense near neighbours and a correction toward one is likelier wrong than helpful

Keep it current

$ tome pull python              # one source
$ tome pull --all                # everything
$ tome pull --all --due          # only what its schedule says is due

Only pages whose content changed are re-indexed, and --due names what it skipped and why, so “did nothing” is distinguishable from “is broken”. Missed schedules coalesce: a laptop closed for six weeks owes one weekly sync, not six.

--due reports manual, pinned, or not-yet-elapsed for each source it passed over

A pull tells you what it missed, too: pages that failed, assets that could not be localized, and whether it stopped at the page cap. A crawl that reports success while having silently skipped two hundred pages is worse than one that says what it missed.
